# CYNOCA TECH — Interactive Multi-Page Website

A polished static website for CYNOCA TECH built with HTML, CSS, and JavaScript. The project includes a modern landing page with animated visuals, a blog section, and an about page for a tech-focused brand.

## What this project includes

- A home page with animated hero content, stats, services, portfolio, testimonials, and contact sections
- A blog page with featured posts, category filters, and community-style content
- An about page with story, values, timeline, team, and culture sections
- Responsive styling and motion effects powered by CSS and JavaScript

## How to run locally

This is a static website, so there is no build step required.

1. Open the project folder in your code editor.
2. Start a local server if you want live preview and reload (recommended: Live Server in VS Code).
3. Open index.html in your browser or visit the local server URL.

## Notes

- The site uses CDN-hosted libraries for fonts, anime.js, and Three.js.
- An internet connection is required for those assets to load correctly.
- Branding, contact details, and content can be updated directly in the HTML files.

## Customization ideas

- Replace the logo in images/logo.jpeg
- Update the company name and tagline in the HTML files
- Edit the copy in the hero, services, portfolio, and contact sections
- Adjust colors and spacing in css/main.css
